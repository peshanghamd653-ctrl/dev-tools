# Folder Structure

```
dev tools/                        # repo root = pnpm root = cargo workspace root
├─ Cargo.toml                     # [workspace] members, shared deps, release profile
├─ package.json                   # frontend deps + scripts (dev/build/test/lint/gen:types)
├─ vite.config.ts                 # tailwind v4, tanstack router plugin, @ alias
├─ vitest.config.ts               # jsdom, src/**/*.test.{ts,tsx}
├─ eslint.config.js               # flat config, strict TS
├─ components.json                # shadcn/ui → src/shared/ui
├─ index.html
├─ docs/                          # this design-document suite
├─ .github/workflows/ci.yml
│
├─ crates/
│  └─ devos-kernel/               # no Tauri dependency; fully unit-testable
│     ├─ migrations/0001_core.sql
│     └─ src/
│        ├─ kernel.rs             # boot, module registration (+ tests)
│        ├─ module.rs             # Module trait + ModuleCtx (future plugin API)
│        ├─ commands.rs           # CommandRegistry (palette contributions)
│        ├─ events.rs             # EventBus (tokio broadcast)
│        ├─ jobs.rs               # JobRunner: durable background jobs
│        ├─ repo.rs               # all SQL (repository pattern)
│        ├─ db.rs                 # pool + migrations
│        ├─ types.rs              # IPC DTOs, ts-rs exported
│        └─ error.rs
│  └─ (M1+) modules/devos-git, devos-terminal, devos-ai, …
│
├─ src-tauri/                     # devos-desktop: thin Tauri shell
│  ├─ tauri.conf.json             # window, CSP, bundling
│  ├─ capabilities/default.json
│  └─ src/{lib,main,commands,state,core_module}.rs
│
└─ src/                           # React 19 frontend
   ├─ main.tsx                    # router + query client
   ├─ app/
   │  ├─ routes/                  # file-based, auto code-split (routeTree.gen.ts)
   │  ├─ components/              # AppShell, Sidebar, Topbar, CommandPalette, dialogs/
   │  └─ nav.ts                   # single source of nav + shortcuts
   ├─ features/<name>/            # hooks.ts (queries/mutations) + page components
   │  ├─ dashboard/ · projects/ · workspaces/ · settings/ · app/
   └─ shared/
      ├─ ipc/client.ts            # ONLY place that calls invoke/listen
      ├─ ipc/bindings/            # generated by ts-rs — do not edit
      ├─ ui/                      # shadcn primitives
      ├─ stores/                  # zustand (ui, dialogs)
      ├─ hooks/                   # useKernelEvents, useGlobalHotkeys
      ├─ lib/utils.ts
      └─ styles/globals.css       # theme tokens
```

Conventions:
- A feature never imports from another feature; go through `shared/` or events.
- New Rust module = new crate under `crates/modules/`, registered in
  `src-tauri/src/lib.rs`, owning its own `migrations/`.
- Generated files (`routeTree.gen.ts`, `ipc/bindings/`) are committed so CI
  and fresh clones typecheck without a Rust build.
